    🛡️ Zero-Retention Privacy Policy & Security
    
        
      
    
      
    
        Your resume contains some of your most sensitive personal and professional data. We believe an ATS screening tool should empower candidates, not collect their data. Here is our absolute privacy commitment:
      
    

      
    
        
    1. Absolute Zero Data Retention (In-Memory Processing)
    
        
    We do not operate any database of candidate resumes. Every screening request is parsed entirely in volatile memory (RAM) and immediately garbage-collected upon response delivery. Nothing is logged to server disks.
    
      
    

      
    
        
    2. Local Client-Side Document Extraction
    
        
    When you drop a PDF or DOCX file onto our tool, the document text is extracted directly inside your web browser using WebAssembly (PDF.js and Mammoth.js). Your original files are never uploaded or stored on any server.
    
      
    

      
    
        
    3. No Model Training
    
        
    All AI analysis is conducted through enterprise Google GenAI endpoints configured under zero-retention API agreements. Your resume content is never used to train or fine-tune AI models.
    
      
    

      
    
        
    4. Prompt & Document Poisoning Shield
    
        
    Our server enforces strict delimiter stripping and XML context isolation (<UNTRUSTED_CANDIDATE_DOCUMENT>). Any adversarial prompt injection embedded inside resumes is neutralized without altering the audit engine.
